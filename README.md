# Güvenle Al-Sat — İkinci El İlan & Pazar Yeri Platformu

Kullanıcıların güvenli, şeffaf ve hızlı bir şekilde ikinci el ürün alım-satımı yapabilmesi için tasarlanmış kapsamlı bir C2C ilan ve pazar yeri platformudur.

## Öne Çıkan Özellikler
- Detaylı İlan Listeleme ve Arama: Kategori, konum, fiyat ve ürün durumuna göre gelişmiş filtreleme mekanizması.
- İlan Verme ve Görsel Yönetimi: Kullanıcıların kolayca ürün ilanı oluşturabilmesi, detay ve çoklu görsel yükleme desteği.
- Kullanıcı Paneli: Aktif ilanların takibi, favorilere eklenen ürünler ve profil yönetimi.
- Güvenli Alım-Satım Mimarisi: Doğrulanmış kullanıcı profilleri, güvenli işlem adımları ve ilan denetim süreçleri.

## Teknolojiler
- ASP.NET Core Web API & React
- C# & TypeScript
- PostgreSQL
- Entity Framework Core
- MinIO / Nesne Depolama
- JWT Kimlik Doğrulama
